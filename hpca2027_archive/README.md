# HPCA 2027 material (not compiled)

The paper was submitted to HPCA 2027 and not accepted; it now targets ISPASS 2027 in the IEEE
conference format. These files belonged only to the HPCA version and are kept here so that history
and the Overleaf project stay readable. Nothing in `hpca2027-latex-template/main.tex` inputs them.

- `00_cover.tex`: the HPCA revision cover page (was typeset from a begin-document hook).
- `00_review_tracker.tex`: the internal reviewer-comment tracker page (generated).
- `hpca-template.tex`: the HPCA author block, header/footer and page style.
- `ae-badges/`: HPCA artifact-evaluation badges, used only by `hpca-template.tex`.
- `TODO.tex`: the HPCA outline and page budget.

The last HPCA state of the whole paper is commit `8c53509` on `main`.
